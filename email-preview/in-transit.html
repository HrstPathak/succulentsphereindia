Production notes

  
Blockers before this can ship

  
    
    
  • The hero is a .webp. — Outlook 2007–2021 and Windows Mail
      cannot decode WebP at all, and some corporate gateways strip it. Re-export as JPEG at 1200×490
      and keep the WebP for the web only. Every other client is fine.
    • 
    
  • The hero must be absolute. It already is —
      https://whitesmoke-cattle-754161.hostingersite.com/sites/images/HomePage/EmailTemplateImage.webp.
      Upload the JPEG alongside it and read the base from a new EMAIL_ASSET_BASE_URL env var, the
      same way ORDER_EMAIL_LOGO_URL works today.
    • 
    
  • Inline SVG is not safe. The status icon, truck, shield and sprout marks are inline
      <svg> so they look right here. Gmail strips inline SVG outright. Each must become a
      hosted PNG at 2x referenced via <img>. Gmail also blocks data: URIs, so
      base64-inlining is not an escape hatch either.
    • 
    
  • The status pill uses the Add to Cart gradient.
      linear-gradient(135deg,#0a8f6a 0%,#12b981 55%,#0a8f6a 100%), copied verbatim from
      components/product/ProductInfo.tsx. A solid #0a8f6a sits underneath it so Outlook
      and any client without gradient support still gets a filled emerald pill with white text.
    • 
    
  • “Happy Planting!” is a cursive system stack for preview only. Real client
      machines carry no script font — ship it as a transparent PNG or set it in Georgia italic.
    • 
  


  
What changed from the previous revision

  
    
    
  • Logo mark removed from the masthead and the footer. It was a drawn SVG, not the real brand asset,
      and it duplicated the wordmark sitting right next to it.
    • 
    
  • Hero is now full-bleed 620px instead of a 42% side column. The supplied image is 2.4:1, so a side
      column was cropping the box of succulents — the exact thing the photo is about. Full width also removed
      the ghost table and the mobile stacking problem entirely.
    • 
    
  • Status pill (IN-TRANSIT / OUT FOR DELIVERY / DELIVERED /
      CANCELLED) sits directly above the headline in the Add to Cart emerald, so the status reads
      before anything else.
    • 
    
  • Trust badge 2 is dynamic. It is the “on the way” slot you flagged — text and icon
      both swap per status. Use the status bar above to check all four.
    • 
    
  • Badges now have a tinted disc and a hairline border. Previously a blocked image left four bare
      white circles. Now a missing icon leaves a designed sage chip that still looks intentional.
    • 
  


  
How the three preview modes map to reality

  
    
    
  • Design — what a client shows with remote images allowed.
    • 
    
  • Images blocked — Gmail and Outlook both block remote images by default. This mode hides every
      <img>. Note the hero still reads: the forest gradient sits behind the photo and the
      status pill and headline are real text, not an image. This is the mode that decides whether the email
      actually works.
    • 
    
  • Legacy / Outlook — Outlook renders HTML through the Word engine, which ignores
      border-radius, linear-gradient, box-shadow and flexbox. This mode strips
      all four so you can confirm nothing collapses or vanishes.
    • 
  


  
Still open, independent of design

  
    
    
  • No plain-text alternative is generated today — email-sender.ts sends only
      { to, subject, html }. The Plain text tab is the proposed replacement, and it is
      regenerated per status too.
    • 
    
  • No preheader exists anywhere in the codebase. One is included here (hidden, at the top of the body) because
      it is the single biggest open-rate lever.
    • 
    
  • 102KB Gmail clip is checked live in the bar above. Gmail truncates past the limit rather than
      rejecting, so a clipped email loses its footer.
