# Succulent Sphere — Next.js Storefront

Premium D2C ecommerce homepage built with Next.js, TypeScript, Tailwind CSS and Framer Motion.

Goals:
- Luxury minimal UI
- SEO & performance optimized (Next/Image, SSR where needed)
- Firebase-backed products, customer accounts, and orders

Getting started:
1. Install dependencies: `npm install`
2. Run dev server: `npm run dev`  

Environment:
- Configure Firebase, Razorpay, email, and optional Delhivery credentials in `.env.local`.
